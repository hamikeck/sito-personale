Pulsante del sito: pillola con bordo 2px a inchiostro, testo bold e ombra piena 2px; usalo per ogni CTA.

```jsx
<Button size="lg">Guarda i progetti ↓</Button>
<Button size="lg" variant="outline">Leggi il blog</Button>
```

variant: default (terracotta) · outline (crema) · secondary (ambra) · ghost · link. size lg = CTA del sito (36px), xl = 44px touch. brut={false} = base shadcn.
